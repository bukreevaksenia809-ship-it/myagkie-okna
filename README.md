# Мягкие окна Excl — чертежи, раскрой и раскладка

![Иконка приложения](build/icon/master-1024.png)

Кроссплатформенное приложение (macOS, Windows и браузер) для параметрического
построения чертежей мягких окон, расчёта раскроя, раскладки полотна на рулонах
(«тетрис» для расхода материалов), ведомости расхода и сохранения заказов.
ПВХ и скрин.

**Версия 2.0.0 («Мягкие окна Excl»).** Готовые сборки и инструкции по выпуску —
в [BUILD.md](BUILD.md).

git-тег `myagkie-okna-1`, архивы исходников и веб-сборки — в папке
`versions/Мягкие окна 1/` (что это и как запустить — `versions/ЧИТАЙ-МЕНЯ.md`).
**Вся дальнейшая разработка идёт здесь — в версии «Мягкие окна Excl».**

## Типы окон — только два

| Тип | Что на чертеже |
|---|---|
| **Глухое** | только круглые люверсы по периметру, от угла до угла |
| **Подъёмное** | сверху от угла до угла только люверсы; ниже по бокам и снизу — скобы-прямоугольники; сверху вниз висят подъёмные ремни |

Молния и карман — **отдельные кнопки**, их можно включить у любого типа окна.

## Материал полотна и рулоны

| Материал | Вид на чертеже | Доступные рулоны |
|---|---|---|
| Обычный ПВХ | голубая полупрозрачная плёнка | 140, 180, 200, 240, 260 см |
| Тонированный ПВХ | более тёмная плёнка | 140, 180, 200, 240 см |
| Москитная сетка | светлая заливка с клеткой сетки | 140, 180, 200, 240, 260, 300 см |
| **Скрин** | простая серая полупрозрачная заливка | 140, 180, 200, 240, 260 см |

Ширина рулона выбирается кнопками из списка **для каждого материала**; раскладка
строится **на отдельном рулоне под каждый материал** заказа.

**Технология выводится из материала, а не задаётся отдельно.** Источник истины
один — `WindowParams.material`: если выбран **Скрин**, окно считается по
технологии `WindowTech.screen` (`isScreen == true`), во всех остальных случаях —
`WindowTech.pvcTent`. Так не бывает состояния «материал ПВХ, а технология
скрина»: всё — расчёт, чертёж, документы — подстраивается под материал.

## Скрин: технология без тента и окантовки

Скрин — **самостоятельная технология**: у него **нет коричневого тента** и **нет
окантовки**. Материал **подворачивается сам** по периметру, крепёж — **только
люверсы по линии подворота** (поворотные скобы, французские замки и ремни
игнорируются, `fastenerType` у скрина не действует).

- **Подворот — своё число на каждую сторону**: `hemBottomMm`, `hemRightMm`,
  `hemTopMm`, `hemLeftMm` (низ, право, верх, лево). Пресеты **40 / 50 / 60 мм**
  на каждую строку и своё значение (10…150 мм). **Шов сварки подворота — 3 мм**
  с каждой стороны (`screenSeamMm`), это константа технологии.
- **Заготовка = готовый размер + подвороты по своим сторонам**: ширина =
  `bottomWidth + hemLeftMm + hemRightMm`, высота = высота стороны +
  `hemBottomMm + hemTopMm`. Для трапеции стороны расширяются каждая по своей
  нормали — ровно так же, как окантовка сужается внутрь. Готовое окно
  **2000 × 2000 мм** при одинаковом подвороте даёт ровно те числа, что называл
  заказчик:

  | Подворот (все стороны) | Заготовка |
  |---|---|
  | 40 мм | **2080 × 2080 мм** (208 см) |
  | 50 мм | **2100 × 2100 мм** (210 см) |
  | 60 мм | **2120 × 2120 мм** (212 см) |

  Смешанный подворот (низ 40, право 50, верх 60, лево 40) на том же окне даёт
  заготовку **2090 × 2100 мм**: ширина выросла на лево + право, высота — на
  низ + верх.
- **Усадки у скрина нет** (`effectiveShrinkagePercent == 0`): ткань не тянется,
  как плёнка ПВХ. Нужен запас — он добавляется обычным **припуском на раскрой**.
- **Окантовки нет**: `edgeConsumption` пустой, готовая полоса нулевая, расход
  тента = 0. Вместо окантовки в документах — строка про подворот и шов 3 мм, а
  **расход скрина считается по площади заготовки** (в примере выше — 4,33 м²).
  Цена полотна скрина — **«Скрин, ₽/м²»** в прайсе, работа подворота —
  **«Подворот скрина, ₽/м»** (₽ за метр периметра готового изделия).
- **На чертеже**: полотно серой заливкой, по периметру — линия подворота (по
  готовому контуру), внутри неё тонкий шов 3 мм (две параллельные линии с
  подписью «шов 3 мм»), люверсы — по линии подворота. **Каждая сторона
  подписана своим подворотом**: «подворот 40» снизу, «подворот 50» справа,
  «подворот 60» сверху, «подворот 40» слева. Коричневого тента нет.
- В панели при выборе скрина **скрываются** разделы «Окантовка», крепёж кроме
  люверсов, молния и дренаж, а вместо них появляется блок **«Подворот, мм»** с
  четырьмя строками (низ, право, верх, лево), у каждой — пресеты 40/50/60 и
  числовое поле, и подпись **«Заготовка будет N × M мм»**.
- **В смете** у окна из скрина есть ровно нужные строки: полотно скрина по
  площади заготовки (**«Скрин: заготовка (габарит) 4,33 м² × 520 ₽/м²»**),
  люверсы по цене люверса с установкой и работа подворота
  (**«Подворот скрина и шов 3 мм: 8,00 м × 180 ₽/м»**, длина — периметр готового
  изделия). Строк про тент, напайку и окантовку у скрина нет.
- **В JSON** подворот хранится четырьмя числами (`hemBottomMm`, `hemRightMm`,
  `hemTopMm`, `hemLeftMm`); старый заказ с одиночным `hemMm` читается как
  одинаковый подворот на все стороны, а когда все четыре равны — одиночное поле
  пишется ещё и для совместимости со старыми версиями.

## Карман: снизу и сверху (отдельные переключатели)

Карман — **полость под утяжитель**. В панели два независимых переключателя:
**«Карман снизу»** (`pocket`) и **«Карман сверху»** (`pocketTop`), ширина кармана
общая.

- Для ПВХ карман делается из тента: полоса **200 мм** складывается пополам →
  готовая ширина **100 мм**. На чертеже это полупрозрачная накладка за кромкой
  (вниз для нижнего, вверх для верхнего) с подписью «карман снизу/сверху»; лист
  удлиняется, чтобы накладка попала в габарит.
- Для скрина карман образуется **подворотом** и рисуется внутри готового контура
  у соответствующей кромки; расход кармана считается так же.
- Углы со стороны кармана **убираются**, а боковые люверсы сдвигаются на **50 мм**
  (вверх для нижнего кармана, вниз для верхнего) — зеркально и симметрично.
- **Расход кармана считается для обоих**: в ведомости и смете каждая полоса идёт
  отдельной позицией, в примечаниях пишется «Карман снизу и сверху».

## Молния (отдельная кнопка «Добавить молнию»)

- Всегда **вертикальная**.
- Впаивается в полосу тента цвета окантовки — **спайку шириной 50 мм**; молния идёт
  строго по середине спайки.
- На чертеже вокруг молнии стоят **стрелки-размеры**: от внутренней кромки плёнки
  до левого края спайки, ширина спайки 50 мм и от правого края спайки до правой
  внутренней кромки окантовки.
- Молния **двигается влево-вправо**: ползунок в разделе «Молния и карман» или поле
  «Положение молнии от левого края». Положение зажато в границах плёнки.
- В раскрое спайка идёт отдельной заготовкой: 50 мм × высота плёнки.

## Пять и более окон: масштаб и детализация

- Режим листа: **«Одно окно»** (по умолчанию) — выбранное окно крупно, с размерами,
  выносками и легендой; окна переключаются списком «Окно №1…№N» в панели.
- Режим **«Все окна»** — обзорная сетка всего заказа; количество окон в ряду
  выбирается: авто, **1 в ряд (подробно)**, 2, 3 или 4.
- В режиме **«1 в ряд»** лист становится выше экрана: каждому окну даётся своя
  полоса высотой 640 точек, чертёж крупный, подписи уменьшены относительно него.
  Такой лист **прокручивается перетаскиванием и приближается колесом**, а кнопка
  «По размеру» подгоняет его по ширине окна. В PDF длинный лист автоматически
  режется на страницы A3.
- Между окнами нет рамок и границ: выбранное окно выделяется светлой подложкой и
  цветной подписью, номера подписаны под каждым окном.

## Окантовка: своя ширина, шов, расход

Ширина окантовки **вводится руками на каждую сторону** (низ, право, верх, лево) —
от **40 до 400 мм** рулона. Пресеты **100 / 200 / 240 мм** остались как быстрые
кнопки: при нажатии ширина подставляется в поле, при ручном вводе чипы просто
не подсвечены. Полоса складывается пополам, поэтому готовая окантовка — половина
рулона: **100 → 50 мм**, **200 → 100 мм**, **240 → 120 мм**, своя ширина — ровно
`рулон / 2` (под полем подписано, сколько получится).

- **Запайка (напайка) плёнки под окантовку вводится руками** — поле «Запайка
  плёнки под окантовку, мм» и быстрые пресеты 10 / 25 / 40 мм. Диапазон
  **5…60 мм**, по умолчанию **25 мм** (`WindowParams.weldOverlapMm`,
  `defaultWeldOverlapMm`). От неё напрямую зависит размер заготовки, поэтому в
  поле и подписана формула. Если готовой полосы не хватает на 2 × запайка,
  приложение предупреждает, что запайке не хватает ленты.
- **Раскрой плёнки** = наружный контур − 2 × (окантовка стороны − запайка);
  видимый размер = наружный контур − 2 × окантовка стороны.
- **Расход окантовки** считается по сторонам без запаса: длины сторон суммируются
  по каждой **ширине рулона**, а не по типу. В смете и ведомости строка
  подписывается шириной: «Тент 150 мм — 150 см».

Пример: окно 1500 × 2520, тент 100 мм на низ/лево/право и 200 мм на верх:

```
Тент 100 мм — 654 см   (150 + 252 + 252)
Тент 200 мм — 150 см
Итого 804 см = периметр наружного контура

видимая плёнка   1400 × 2420 мм
раскрой          1450 × 2470 мм
с усадкой 1,5 %  1472 × 2507 мм
```

**Пример заказчика с запайкой 10 мм.** Готовое окно **2000 × 2000**, окантовка
100 мм (готовая 50) по бокам и низу, сверху 80 мм (готовая 40), запайка **10 мм**:

```
ширина заготовки  2000 − 100 + 2 × 10 = 1920 мм
высота заготовки  2000 −  90 + 2 × 10 = 1930 мм
```

Эти числа закреплены тестом `window_geometry_test.dart`. У скрина поля запайки
нет: вместо неё — подворот, см. раздел «Скрин».

**Цена нестандартной ширины.** В прайсе есть цены трёх пресетов (₽/м). Для своей
ширины цена линейно интерполируется между двумя ближайшими пресетами, а за
пределами диапазона 100…240 мм — экстраполируется по ближайшему отрезку: 150 мм
считается ровно посередине между ценой 100 и 200 мм, 240+ продолжает отрезок
200…240. Так смета не «прыгает» в цену соседнего пресета.

## Припуск на раскрой

**Припуск на раскрой влияет только на заготовку плёнки.** Изделие — это
введённые основные размеры (`bottomWidth`, `topWidth`, `leftHeight`,
`rightHeight`). По ним строятся чертёж, окантовка, люверсы, спайки, периметр и
площадь изделия; припуск их не меняет. В окне два поля — **припуск по ширине**
и **припуск по высоте**, по умолчанию 0.

- Припуск по ширине прибавляется и к низу, и к верху, припуск по высоте — и к
  левой, и к правой высоте, но только в раскрое плёнки.
- **Пример**: изделие **2000 × 2000 мм**, окантовка 100 мм (готовая 50),
  напайка 25 мм, припуск **+100/+100**.
  - Изделие и чертёж — **2000 × 2000 мм**, площадь изделия **4,00 м²**.
  - Плёнка в раскрое по изделию: `2000 − 2 × 25 = 1950` → **1950 × 1950 мм**
    (`filmCutWidth` / `filmCutHeight`).
  - Заготовка с припуском: **2050 × 2050 мм**
    (`filmCutWidthWithAllowance` / `filmCutHeightWithAllowance`).
  - Заготовка с усадкой 1,5 %: **2 081 × 2 081 мм**
    (`filmCutWidthWithShrinkage` / `filmCutHeightWithShrinkage`).
  - Площади: заготовка (габарит) без усадки `filmCutAreaM2` = **4,20 м²**
    (2050 × 2050), она же с усадкой `filmCutAreaWithShrinkageM2` = **4,33 м²**
    (2080,75 × 2080,75). **Усадка компенсируется по обеим сторонам**, поэтому
    площадь с усадкой считается из линейных размеров, а не умножением площади
    на один множитель. В расход и деньги идёт именно площадь с усадкой.
- **Что от чего считается**:
  - по основным размерам — `WindowGeometry.of()`, чертёж, окантовка
    (`WindowLayers.edgeConsumption`), люверсы и их шаг, периметр, спайки,
    `productAreaM2` и справочная `filmAreaM2` (площадь полотна изделия без
    припуска);
  - с припуском и усадкой — `filmCutWidthWithAllowance` /
    `filmCutHeightWithAllowance`, `filmCutWidthWithShrinkage` /
    `filmCutHeightWithShrinkage`, `filmCutAreaWithShrinkageM2` и раскладка
    заготовок на рулоне. Именно эти значения идут в расход материала, смету,
    ведомость и техкарту (операция «Раскрой плёнки»).
  - `filmCutAreaM2` — **габарит** заготовки (прямоугольник), `filmAreaM2` —
    **полотно** изделия по контуру. Для трапеции габарит больше полотна, и в
    подписях это разведено: «заготовка (габарит)» против «площадь полотна».
- **В документах** припуск не подменяет размеры изделия: на чертеже и в штампе
  видны основные размеры (2000 × 2000) и площадь изделия (4,00 м²), в ведомости
  расхода — те же размеры полотна, а колонки про плёнку показывают заготовку
  (2 050 × 2 050 мм и площадь заготовки (габарит) 4,20 м²; с усадкой 4,33 м²).
  Единственная справка о припуске — строка в примечаниях: «Припуск на раскрой:
  ширина +100 мм, высота +100 мм — плёнка кроится 2 050 × 2 050 мм». Лист
  «Раскрой» и раскладка на рулоне показывают заготовки уже с припуском.
- Припуск вне диапазона **0…500 мм** — предупреждение; **отрицательный**
  припуск тоже предупреждение (заготовка получится меньше замера), но не
  ошибка: ввод не блокируется.
- Припуск хранится в JSON заказа (`allowanceWidthMm`, `allowanceHeightMm`) и
  переживает сохранение и загрузку без потерь.

## Люверсы

- Идут **от угла до угла**: `шаг = длина стороны / ceil(длина / номинал)`, фактический
  шаг всегда не больше номинала — «хвоста» в углу нет.
- Угловые люверсы соседних сторон склеиваются: каждый угол считается один раз.
- Отступ от угла по умолчанию 0 (люверс в углу), диапазон 0…70 мм.
- Тип: круглый Ø10 мм; овальный 42×22 мм — только у подъёмных окон, у глухих
  всегда круглые.
- Подъёмные ремни: **2 шт при ширине до 2 м**, далее **+1 ремень на метр**
  (2500 → 3, 3200 → 4), заготовка 50 × 500 мм.

## Ввод чисел с клавиатуры

Поля размещают ввод свободно: пока вы печатаете, текст и значение модели
совпадают, поэтому приложение не переписывает поле и **курсор с выделением не
сбрасываются**. Поле обновляется только при внешнем изменении (пресет, смена
окна, «Сбросить»). Незавершённый или неверный ввод сохраняется как есть и
подсвечивается ошибкой.

## Приближение чертежа

- Колесо мыши или трекпад — масштаб, перетаскивание — сдвиг.
- Кнопки `−` / `+`, текущий процент и «По размеру».
- Масштаб не влияет на экспорт: в PDF попадает лист целиком.

## Реалистичная отрисовка и читаемый масштаб

- **Окантовка** — коричневый тент: градиент по толщине полосы, тканевая фактура
  (поперечные и продольные нити), строчка по сгибу, потому что полоса
  складывается пополам.
- **Плёнка** — полупрозрачный ПВХ: видно сетку листа, добавлен косой блик
  (тонированный ПВХ темнее, москитная сетка — с мелкой клеткой).
- **Люверсы** — металлические кольца: радиальный градиент металла, блик,
  фаска вокруг отверстия и само отверстие со светлой подложкой.
- **Поворотные скобы** — пластина с саморезами и проволочная петля, нарисованная
  «трубкой» (тёмный контур, металл, блик) плюс стрелка поворота.
- **Французские замки** — планка с двумя саморезами, поворотный рычажок под 45°
  с осью и дуга поворота на 90° со стрелкой.
- **Молнии** — полоса тента, зоны напайки по краям, два ряда зубцов с замком,
  бегунок с язычком и ограничители.
- **Масштаб** — чертим в честном стандартном масштабе (1:10, 1:15, 1:20 …),
  так что подпись в штампе совпадает с реальностью и с масштабной линейкой.
  Линейка — с чередующимися делениями, подписями и штампом масштаба.
- Толщина окантовки на мелком масштабе не тоньше 5 точек — чертёж читается
  без лупы, даже когда на листе 5 окон.

## Молнии, вырезы и спайка окон

- **Молнии** — до двух на окно (кнопка «Добавить молнию», затем «Добавить вторую
  молнию»): у каждой своё положение (по центру или от левого края слайдером)
  и своя ширина спайки 40–120 мм. Цепочки размеров у второй молнии идут ниже,
  чтобы подписи не налезали.
- **Вырезы** — до четырёх на окно (прямоугольные и круглые) под трубу,
  вентиляцию или стойку: центр задаётся от левого края и от низа полотна.
  Вырез — настоящее отверстие в плёнке, по его контуру идёт окантовка со швом
  напайки, а расход окантовки увеличивается на периметр выреза.
  Программа предупредит, если вырез выходит за полотно, налезает на полосу
  молнии или пересекается с другим вырезом.
- **Спайка окон между собой** — четыре стороны: чипы «Спаяно слева», «Спаяно
  справа», «Спаяно сверху», «Спаяно снизу». На спаянной стороне окантовка не
  ставится (полотна свариваются внахлёст 25 мм), расход окантовки уменьшается
  ровно на длину этой стороны, а в ведомости появляется строка про спайку.
  На чертеже такая сторона показана штриховкой и подписью «спайка 25» — и для
  боковых, и для верхней и нижней кромок.
- **«Добавить окно к спайке» (сверху/снизу/слева/справа)** — копия выбранного
  окна встаёт сразу после него и варится с ним по указанной стороне: у текущего
  окна появляется эта сторона, у копии — противоположная (право↔лево,
  верх↔низ). Копия повторяет шаблон целиком — размеры, материал, окантовку,
  молнии, вырезы, карман; отличается только маркировка (`drawingNumber`
  очищается) и номер окна. Повторное нажатие по уже спаянной стороне сторону
  не дублирует. Так собирается цепочка одинаковых полотен в один заказ.
- **Люверсы на спайке убираются** — переключатель «Убирать люверсы (крепёж) на
  спаянной стороне» (по умолчанию включён): по сварному шву крепёж только рвёт
  тент — и на верхней, и на нижней стороне тоже. Если по технологии люверсы на
  спайке нужны — выключите переключатель.
- **В углах всегда круглые люверсы** — овальные 42×22 ставятся только по
  сторонам: угол тянет по диагонали, круглый там держит лучше. Это видно и на
  чертеже, и в легенде.

## Всегда подробный чертёж

Каждое окно на листе рисуется **в подробном режиме** — с размерами, выносками,
кромками и подписями молний, независимо от того, одно окно в заказе или десять.
Лист при этом растёт: одна строка на окно (или на ряд из 2–4 окон), поэтому
ничего не мельчает. Лист одного окна строится по пропорциям окна, а не
растягивается на весь экран, — чертёж получается крупным и аккуратным.

- В углах **всегда круглые люверсы** (овальные 42×22 — только по сторонам):
  угол тянет по диагонали, а на стыке сторон поворотная скоба выглядела бы
  прямоугольником вместо люверса.
- Поворотные скобы, замки и ремни ставятся **по сторонам, не в углах**.

## Удобство работы с заказом

- **«Дублировать»** — копия выбранного окна вставляется следующей: заказ из
  одинаковых окон собирается в два клика, а потом правятся отличия.
- Лист одного окна чертится **в аккуратной рамке по пропорциям окна** (а не
  растягивается на весь экран), в боковой панели — карточка **«Масштаб листа»**
  с линейкой и пояснением, что при печати без масштабирования размеры сходятся
  с линейкой.

## Площадь готового изделия

Везде показываются две площади, чтобы их не путать:

- **площадь изделия** — по наружному контуру окна (габарит): для окна
  1500 × 2520 мм это **3,78 м²**. Именно она идёт в прайс заказчику;
- **площадь плёнки** — сколько плёнки уходит в раскрой с запайкой (по умолчанию 25 мм)
  (для того же окна **3,58 м²**).

Площадь изделия видна: в раскрое на панели, в подписи окна на листе, в штампе
(«Площадь изделий» / «Площадь плёнки»), в строке итогов внизу и в ведомости
расходов отдельными колонками и итогом по заказу. Для трапеции площадь
считается по четырём углам, а не по габаритному прямоугольнику.

## Вкладка «Смета»: деньги заказа

Прайс-лист живёт в панели слева (раздел **«Прайс-лист»**): цены за м² плёнки по
материалам (включая строку **«Скрин, ₽/м²»**), за метр окантовки по пресетам
рулонов 100/200/240 мм (для своей ширины цена интерполируется), люверс, молния,
спайка, карман, ремень, дренаж, вырез, сборка, раскрой и работа подворота
скрина (**«Подворот скрина, ₽/м»** — за метр периметра готового изделия), а
сверху — наценка, скидка и НДС. Расчёт идёт строго из ведомости расхода, вручную
ничего пересчитывать не нужно.

Плёнка и раскрой считаются по площади **заготовки (габарит) с усадкой** — той,
по которой реально кроится полотно. Для трапеции это габаритный прямоугольник,
он больше «площади полотна», и в подписях документов эти числа разведены.

Лист «Смета» — готовый документ для клиента: позиции по разделам (материалы,
фурнитура и спецэлементы, работы), количество с единицами, цена, сумма,
подытоги по разделам, наценка, скидка, НДС сверху и **ИТОГО к оплате** крупно,
цена за одно окно, состав заказа и использованные цены прайса, штамп снизу.
Пример: глухое окно 1500×2520 на ценах по умолчанию — 12 863,16 ₽ с НДС.

У окна из скрина в смете ровно свои строки: **«Полотно: Скрин»** по площади
заготовки (2000 × 2000 с подворотом 40 мм → 4,3264 м² × 520 ₽/м² = 2 249,73 ₽),
**«Люверсы»** по цене люверса с установкой (28 шт) и **«Подворот скрина и шов
3 мм»** по периметру готового изделия (8,00 м × 180 ₽/м = 1 440,00 ₽). Строк про
тент, напайку и окантовку у скрина нет. Тот же пример целиком — **12 109,60 ₽**
с НДС.

## Вкладка «Техкарта»: что делать в цеху

Технологическая карта строится по каждому окну заказа: 11 операций в порядке
реальной технологии — раскрой плёнки (с запайкой 5…60 мм и усадкой), запайка и
сварка, спайка с соседним окном, окантовка по сторонам с длинами и ширинами
полос, люверсы (количество, шаг, отступ, правило «в углах только круглые»),
молнии с шириной спайки, вырезы с координатами, карман, ремни, дренаж и
контроль перед упаковкой. У каждой операции — что делать и с какими размерами,
какой инструмент нужен и что проверить. Все числа берутся из модели, ничего
не выдумано.

![Технологическая карта](docs/пример-техкарта.png)

## Раздел «Технолог»: проверки до цеха

Отдельный раздел в панели показывает производственные замечания с пояснением и
рекомендацией: парусность при большом шаге люверсов или слишком частом шаге,
люверс «почти в углу», тонкая окантовка и нехватка запайки, узкое полотно и
слишком большая площадь (свыше 12 м²), нагрузка на ремни и высота подъёма,
сближение молний и близость молнии к кромке, вырез с тонкой перемычкой,
спайка с крепежом на той же стороне, оба спаянных бока, овальный люверс у
глухого окна, «только люверсы» у подъёмного, нетиповая усадка и сложная
трапеция. Плюс проверки по заказу: одинаковые окна, больше двух материалов
плёнки, суммарная площадь свыше 40 м². Проблемы делятся на подсказки,
предупреждения и ошибки — ошибка подсвечивает раздел красным.

## Вкладка «Расходы»

Отдельная вкладка с **ведомостью расхода материалов** по заказу:

- таблица по каждому окну: тип, материал полотна, размеры, полотно в раскрое с
  усадкой, **площадь изделия** и площадь заготовки (габарит) с усадкой, люверсы,
  окантовка / подворот по сторонам, спецэлементы (молния, карман, ремни, дренаж);
- для скрина в графе «Окантовка / подворот» стоит подворот по сторонам
  (например «подворот 40/50/60/40 мм»), а в итогах — отдельный блок «Скрин:
  подворот и шов 3 мм» с перечислением сторон и длиной подворота по периметру;
- итоги по заказу: полотно по материалам (площадь заготовки (габарит) с
  усадкой), окантовка по ширинам рулонов, люверсы по типам, сопутствующие
  материалы (спайка молнии, карман, подъёмные ремни), раскладка на рулонах с
  процентом отхода;
- лист можно сохранить в PDF и напечатать так же, как чертёж и раскладку.

## Сохранение заказов (отчётность)

В панели слева есть раздел **«Заказы (отчётность)»**:

- **«Сохранить заказ»** пишет JSON с параметрами всех окон и готовой сводкой
  расхода в `~/Downloads/Мягкие окна/Заказы/<дата>-<название>.json`;
- список сохранённых заказов показывает дату, число окон, площадь плёнки,
  количество люверсов и расход окантовки;
- заказ можно **открыть** обратно в программу (все параметры восстанавливаются)
  или **удалить** файл;
- битые файлы не ломают список.

## Печать и экспорт PDF

- Кнопка **«Сохранить чертёж»** / **«Сохранить раскладку»** сохраняет лист:
  ```
  ~/Downloads/Мягкие окна/Чертёж-МО-014-20261003-1200.pdf
  ~/Downloads/Мягкие окна/Раскладка-МО-014-20261003-1200.pdf
  ```
- Кнопка **«Печать»** открывает системный диалог печати macOS (плагин `printing`,
  право `com.apple.security.print` в entitlements).
- Лист, который влезает на A3, идёт одной страницей по своим пропорциям.
- Длинный подробный лист режется на страницы **по границам окон**: одно окно —
  одна страница (плюс последняя страница со штампом заказа). Окно никогда не
  разрывается пополам, страницы не выше A3.
- Каждая страница PDF — **свой вырезанный кусок листа** (раньше на страницы
  после первой попадала пустота, это исправлено и покрыто тестом на вырезание).

## Принятые допущения

- Форма строится по четырём замерам; нижняя и верхняя кромки горизонтальны,
  окантовка — равномерный отступ по каждой стороне (своя ширина в мм на каждую
  сторону; пресеты 100/200/240 — быстрые кнопки, готовая полоса = рулон / 2).
- Углы прямые (скруглений нет).
- Спайка молнии — полоса тента 100 мм, сложенная пополам (готовая 50 мм);
  молния по её середине.
- Овальный люверс: внешние 42×22 мм, отверстие принято 30×11 мм.
- Расход окантовки — сумма длин сторон, запас на стыки не заложен.
- Молния и карман не меняют раскрой плёнки: они идут отдельными заготовками;
- Скрин — отдельная технология без тента и окантовки: подворот задаётся **на
  каждую сторону** (низ, право, верх, лево — 10…150 мм, пресеты 40/50/60), шов
  3 мм, крепёж только люверсы; заготовка = готовый размер плюс подворот по
  сторонам (2000 × 2000 при одинаковом подвороте 40/50/60 мм → 2080/2100/2120 мм;
  смешанный 40/50/60/40 → 2090 × 2100 мм). В смете у скрина полотно по площади
  заготовки, люверсы и работа подворота по периметру.
- Контуры вырезов в расходе окантовки всегда идут в нижний рулон (низ), даже
  если нижняя сторона спаяна с соседним окном, — это осознанное упрощение
  раскроя.

## Ограничения

- PDF содержит лист как изображение высокого разрешения (не вектор).
- Раскладка полочная, без полного перебора — оптимальность не гарантируется,
  но длина рулона считается по факту укладки.
