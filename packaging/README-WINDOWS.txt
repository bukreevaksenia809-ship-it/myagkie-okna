МЯГКИЕ ОКНА EXCL — версия для Windows
=====================================

Как запустить
-------------
1. Распакуйте архив ЦЕЛИКОМ в любую папку (например, C:\Мягкие окна Excl).
   Важно: рядом с MyagkieOknaExcl.exe должны лежать папка data и файлы .dll —
   по одному exe приложение не работает.
2. Запустите MyagkieOknaExcl.exe.

Если Windows пишет «Windows protected your PC»
---------------------------------------------
Приложение не подписано платным сертификатом, поэтому SmartScreen
предупреждает при первом запуске. Нажмите:
   «Подробнее» → «Выполнить в любом случае».
Дальше приложение запускается обычно. То же самое может сказать антивирус —
это обычное поведение для неподписанных программ.

Где приложение хранит файлы
---------------------------
Чертежи в PDF:      <Домашняя папка>\Downloads\Мягкие окна
Сохранённые заказы: <Домашняя папка>\Downloads\Мягкие окна\Заказы

Что умеет
---------
• чертёж мягкого окна: окантовка по сторонам, напайка 25 мм, плёнка,
  люверсы, молния, карман, ремни, дренаж;
• режимы «Одно окно» и «Все окна» (1–4 в ряд), масштаб и прокрутка;
• раскладка заготовок на рулонах по материалам с процентом отхода;
• ведомость расхода материалов с площадью изделия и площадью плёнки;
• сохранение заказов в JSON для отчётности;
• экспорт в PDF и печать.

Требования
----------
Windows 10 или 11, 64-бит. Установка не нужна — приложение портативное.
