# Публикация в RuStore

## Готовые файлы

- `icon-512.png` — иконка 512×512;
- `feature-1024x500.png` — feature graphic;
- `screen-1-settings.png`, `screen-2-shapes.png`, `screen-3-edges.png` — 3 скриншота 1080×1920 (16:9);
- `listing.md` — тексты карточки;
- `privacy-policy.md` — черновик политики (заменить реквизиты клиента).

Установочные файлы (не коммитятся, лежат в `build/`):

- `build/app/outputs/flutter-apk/app-release.apk` — подписанный APK;
- `build/app/outputs/bundle/release/app-release.aab` — AAB.

## Что уже настроено

- release-подпись: `android/upload-keystore.jks` + `android/key.properties` (в git не попадают);
- package: `ru.myagkie.soft_window_drawer`;
- versionName **1.6.0**, versionCode **6**;
- minSdk **26** (Android 8.0 — требование RuStore);
- название на устройстве: **Калькулятор мягких окон**;
- интернет-разрешение;
- CI собирает подписанные APK и AAB из GitHub Secrets.

Ключ и пароли: `../soft_window_drawer_keys/` (рядом с проектом, **не в git**).  
Сделайте резервную копию — без него нельзя выпускать обновления.

## Первая публикация

1. Зарегистрируйтесь в [RuStore Консоль](https://console.rustore.ru) через VK ID.
2. «Приложения» → «Добавить приложение» → название **Калькулятор мягких окон**.
3. «Загрузить версию» → APK `app-release.apk` (или AAB).
4. Заполните карточку по `listing.md`, загрузите иконку и 3 скриншота.
5. Укажите данные/разрешения, возрастной рейтинг, контакты.
6. В комментарии модератору дайте тестовый ключ активации:
   `YE9J-EMDP-37DA-B9DT`.
7. Отправьте на модерацию.

## Обновления

1. Поднимите версию в `pubspec.yaml`: например `1.6.0+6` → `1.6.1+7` (versionCode обязательно больше).
2. Обновите `kAppVersion` в `lib/main.dart`.
3. Соберите/запушьте — CI соберёт подписанные APK/AAB.
4. RuStore Консоль → приложение → «Загрузить версию» → тот же package и та же подпись.
5. После модерации пользователи получат обновление через RuStore.

## Важно

- Package name и ключ подписи менять нельзя.
- Не удаляйте `android/upload-keystore.jks` и `key.properties`.
- В публичной сборке остаются телеметрия и удалённый просмотр файлов — это может вызвать вопросы модерации. Если отклонят, нужно будет сделать «магазинную» сборку без этих функций.
- Приложение требует ключ активации; модератору нужен тестовый доступ.
