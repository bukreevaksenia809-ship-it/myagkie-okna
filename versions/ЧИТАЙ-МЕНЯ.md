# Версии приложения «Мягкие окна»

В этой папке лежат зафиксированные (архивные) версии приложения. Папка
`versions/` добавлена в `.gitignore`: сами архивы в git не попадают, в
репозитории остаётся только исходный код и теги.

## Мягкие окна 1 — зафиксированная версия

- **Git-тег:** `myagkie-okna-1` (аннотированный, сообщение «Мягкие окна 1»).
- **Что это:** первая выпущенная версия приложения: чертежи мягких окон,
  раскрой, раскладка на рулонах, ведомость расхода, прайс-лист и смета,
  технологическая карта. ПВХ и скрин. Работает на macOS, Windows и в браузере.
- **Состояние кода:** версия `1.1.0+4` из `pubspec.yaml`, ветка `main`,
  коммит, на который указывает тег `myagkie-okna-1`.
- **Дальнейшая разработка идёт в версии «Мягкие окна Excl»** (см. корневой
  `README.md`, `BUILD.md` и `WEB-DEMO.md`). Всё, что делается дальше, делается
  в `main` поверх этого тега; версия «Мягкие окна 1» больше не меняется.

### Как запустить эту версию из исходников

```bash
# распаковать архив
mkdir -p myagkie-okna-1 && tar -xzf myagkie-okna-1-source.tar.gz -C myagkie-okna-1
cd myagkie-okna-1

export PATH="/Users/davidovjr7/Downloads/flutter/bin:$PATH"
flutter pub get

# запустить на компьютере (macOS/Windows/Linux)
flutter run

# собрать релиз под текущую платформу
flutter build macos --release      # macOS → build/macos/Build/Products/Release/MyagkieOkna.app
flutter build windows --release    # Windows → build/windows/x64/runner/Release/MyagkieOkna.exe

# собрать веб-версию
flutter build web --release        # результат в build/web
```

Готовая веб-сборка из `myagkie-okna-1-web.zip` запускается без Flutter:
распакуйте zip в любую папку и поднимите статический сервер, например
`python3 -m http.server 8080` в этой папке, затем откройте
`http://localhost:8080`. Без сервера (file://) приложение не заработает.
