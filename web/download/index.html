Версия 2.9.1

Копия 2 для Windows

Та же программа, что на сайте, но отдельным приложением для Windows 10/11. Сметы и отчёты клиенту/дилеру, цветные складские позиции, импорт DOCX и расход тента — в этой версии.

Скачать Копию 2 для Windows
Как запустить:
  • Скачайте ZIP.
  • Распакуйте всю папку, не запускайте из архива.
  • Запустите MyagkieOknaExcl.exe.
  • Если Windows покажет предупреждение SmartScreen — «Подробнее» → «Выполнить в любом случае».
Если антивирус удалит файл, добавьте папку программы в исключения и распакуйте заново.

Версия 2.9.1

Копия 2 для Android

Мобильная версия: те же расчёты, документы, склад и саморезы. Подходит для телефона и планшета Android 8+.

Скачать APK для Android
Как установить:
  • Скачайте APK на телефон.
  • Откройте файл и разрешите установку из этого источника.
  • Если загрузка из браузера не открывается — повторите через «Загрузки».
Для Google Play используется файл .aab: он выгружается в консоль Play.
