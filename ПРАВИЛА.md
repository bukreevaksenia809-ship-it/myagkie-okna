## Не менять без согласования с заказчиком
1. Припуск влияет ТОЛЬКО на заготовку плёнки; изделие, чертёж, окантовка и люверсы не меняются.
2. Скрин — отдельная технология: без тента, подворот по сторонам, шов 3 мм, крепёж по подвороту, окантовки нет.
3. Подворот скрина: в заготовку идёт ПОЛОВИНА подворота каждой стороны; ширина = готовая ширина + лево/2 + право/2, высота = готовая высота + низ/2 + верх/2 + 20 мм. Пример: 1000 × 1000, подвороты 80/80/120/80 → 1080 × 1120.
4. ПВХ: заготовка = сторона − 2 × готовая полоса + 2 × запайка, по КАЖДОЙ стороне отдельно (косые окна — так же, с рисованием косой формы на раскрое).
5. Запайка по умолчанию 5 мм; авто-припуск +10 мм к высоте — только для ПВХ; усадка по умолчанию выключена.
6. Углы — круглые люверсы, есть тумблер отключения круглых; расстановка детерминированная.
7. Молния: полоса вычитается из ширины заготовки (и ПВХ, и скрин).
8. «Ровно»: низ / верх / нет, по умолчанию низ; для старых заказов — прежнее поведение.
9. А4-лист чертежа и страницы PDF A4; печать — с выбором листов; единицы мм/см только для отображения (внутри всё в мм).
10. Цены: любая позиция прайса включается/выключается и не попадает в смету, если выключена.
